## 📈 My Approach

For each problem, I try to understand:

1. What is the problem?
2. What is the simplest approach?
3. How does the algorithm work?
4. How can it be implemented in C?
5. What is the time complexity?
6. What is the space complexity?
7. What edge cases should be considered?

The focus is on **understanding the logic and implementation**, not just memorizing solutions.
